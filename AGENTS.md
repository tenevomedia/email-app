# Mandatory Git Workflow Guidelines for AI Agents

> ⚠️ **CRITICAL RULE FOR ALL AI AGENTS WORKING ON THIS REPOSITORY:**
> 
> 1. **Commit Every Change:** After completing any task, fix, or feature implementation, you MUST create a Git commit.
> 2. **Detailed Commit Messages:** Every commit message MUST be descriptive and detailed, clearly explaining what changes were made, why they were made, and which files were affected (e.g. `feat: add settings page with custom From identity management and theme options`).
> 3. **Immediate Push:** Immediately after committing, you MUST push all commits to the remote GitHub repository (`git push origin main`). Never leave unpushed commits at the end of a turn.
